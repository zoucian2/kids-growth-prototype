# 小小成長島 · v0.4

網址：https://zoucian2.github.io/kids-growth-prototype/

無建置步驟、無外部套件的靜態網站；main 根目錄由 GitHub Pages 發佈。

## 使用

- 開啟或重新整理先選哥哥（跆拳道）、妹妹（街舞）、弟弟（滑步車）或家長；孩子端「換使用者」回到入口。
- 家長原型 PIN **1234**，僅防誤觸，不是安全帳號。家長可切換目前陪伴的孩子。
- 每日／支線以裝置本地日期每天完成一次；冒險每項只完成一次。需要家長確認的任務，確認後才發放點數。
- 第一次、重要成長時刻、冒險任務先顯示「我學會了」，再顯示收穫；一般重複任務直接顯示收穫。

## 情緒小旅程

9 種感受 → 強度 1–3 → 發生什麼（含不知道／暫時不想說）→ 9 種方法 → 試過後的回顧。

方法：深呼吸、喝點水、動一動、安靜一下、抱一下、畫出來、找人說說、說出我的需要、請人陪著我。每個有具體步驟、學習句及瀏覽器朗讀入口；實際語音視裝置提供的中文語音而定。

可以選「還沒想試」，可以回報感受沒變或更強烈，不強迫平靜。能力徽章只記錄覺察／表達／嘗試，不給星星、金幣或 XP。重複練習徽章按不同日期計算，不鼓勵同日刷次數。

## 三種資源與家長規則

- ⭐ 星星：現實獎勵。品項、名稱、價格、開放狀態由家長編輯，適用全家。
- 🪙 金幣：世界內動物／裝飾，與星星獨立。
- 🌱 成長值（XP）：只累積不花掉，影響世界成長。

最初三個兌換品項只作為家庭可修改的起始範例，不是固定的產品定價。沒有星星與現金的通用匯率。

孩子可選目標、存放星星、拿回星星。目標內星星仍屬於總餘額，但不能同時拿去申請其他獎勵：可用＝總額－目標存放－待確認保留額。換目標先確認，原存放額回到可用。兌換仍由家長確認；取消不扣星。價格變更不重算已提交申請或歷史紀錄。

家長可編輯各孩子任務的星星、金幣、成長值。只適用下一次完成；完成時的報酬快照不變。既有任務不改週期，避免當日重複領取。品格與關懷強制三種報酬均為零。

## 資料相容

仍使用 localStorage `kids-growth-v02`、version 2，新增 rulesVersion 3。從 v0.2 升級先保存原始備份至 `kids-growth-v02-before-rules-v3`，再加入新欄位。保留原星星、成長、任務、情緒、兌換與成長紀錄；不追溯發放金幣，舊待確認任務也不加金幣。新任務或後續完成依新設定累積金幣。

資料不跨裝置同步；清除網站資料會遺失。家長可下載 JSON 備份，目前沒有匯入介面。讀寫失敗會提示並停止操作，不自動清空資料。

## 規則依據與本次範圍

重新讀取專案對話「母架構及核心理念」（6ac4b381-cc28-83ee-953b-245e6834d960）中任務／點數／兌換／情緒的詳細架構，以及「系統介面討論」（6ac51ce5-b9b8-83e8-93dd-adbedfb92698）中先學習、後獎勵的流程。

取得的母架構附件實際只有標題，所以沒有把附件當作完整規格。以對話可核對內容與本次使用者三項修正為依據；好友、家庭共同任務、完整家長成長等未納入此次範圍。

本次將情緒原有 6 個方法擴為 9 個；用能力紀錄取代情緒數值排名；5 次練習徽章按不同日期計算，避免刷紀錄。尚未實作全面圖片朗讀、好友系統或大型世界。

## v0.4：四區成長護照與財商學習

依使用者確認，護照只分「生活／情緒／關係／財商」四區。舊資料按原有 kind 與 skill 分類呈現，不重寫歷史；生活任務歸生活，情緒紀錄歸情緒，品格關懷及被看見歸關係，新增財商學習歸財商。每區顯示最近三則，更多紀錄可展開。

獎勵頁加入財商小學堂：認識三種資源、需要與想要、選擇與等待。互動選擇後提供說明，收藏進財商護照；同一練習每位孩子只收藏一次，不發放任何貨幣。第一次實際儲蓄與每筆家長確認兌換也留下財商故事。

收支明細由已核准任務與兌換紀錄產生；存放星星及待審核不是支出。不推算沒有紀錄的期初餘額。兌換前顯示可用星星、此次花費及剩餘可用額，提醒目標的取捨，保留「先等等」選項。

新增 learning.js：護照區塊、財商頁面與學習互動。儲存格式不變，舊資料與余额保留。驗證包含四區分類、練習去重與孩子隔離、點數不變、儲蓄與支出區分、重整保存及平板／手機版面。
