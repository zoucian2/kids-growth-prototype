# 小小成長島 · MVP v0.2

網址：https://zoucian2.github.io/kids-growth-prototype/

無建置步驟、無外部套件的靜態網站。GitHub Pages 從 main 根目錄發佈。

## 使用

- 上方切換哥哥（跆拳道）、妹妹（街舞）、弟弟（滑步車）；每位孩子獨立保存。
- 今天、成長護照、心情、獎勵、世界均可使用。
- 每日／支線以裝置本地日期每天完成一次，冒險每項只完成一次。需要確認的任務待家長確認後才發放星星／成長。
- 家長 PIN **1234**，僅供原型防誤觸，不是安全機制。可確認任務／兌換、新增預設或自訂任務、記錄被看見的片刻、下載 JSON 備份。
- 冰淇淋 300、遊戲多 30 分鐘 500、選週末活動 1000 星；申請先保留可用額度，家長確認才扣除兌換星星。取消不扣星、不可重複確認。
- 世界按成長值 20／80／200 增添風景，休息不倒退，兌換不影響成長。

## 資料與教育規則

localStorage key: `kids-growth-v02`，schema version 2。v0.1 的 580 星是硬編碼展示，沒有可遷移的持久資料；v0.2 從 0 開始真實累積。

資料只留在同一瀏覽器，不跨裝置同步。清除網站資料會遺失紀錄。下載備份供留存，目前沒有匯入功能。讀取損毀或寫入失敗會顯示提醒；不自動清空原資料。

不因漏做扣分、不排名或比較孩子、不把星星換算現金。情緒與被看見的紀錄不給星星／成長值；自訂「品格與關懷」任務強制為 0 星、0 成長值。所有感受都可以被記錄。

## 維護與驗證

- `index.html`: 頁面入口
- `style.css`: 響應式介面
- `model.js`: 資料、任務、兌換規則
- `app.js`: 介面與瀏覽器保存
- `node --test tests/model.test.cjs`: 資料邏輯測試
- `node tests/browser.cjs`: 需已安裝 Playwright 與 Edge；啟動本地伺服器並用全新、隔離的瀏覽器環境進行流程測試。
- 設定 `TEST_URL` 可測正式網站，測試資料僅寫在隔離測試瀏覽器的 localStorage，不會修改其他使用者資料。

瀏覽器涵蓋：完成與學習句、重整、三人分離、三個情緒工具與強度、PIN、任務確認、被看見、預設／自訂任務、品格零分、兌換確認／取消、世界成長、1180×820 平板與 390×844 手機、跨分頁同步、損毀資料保護。
