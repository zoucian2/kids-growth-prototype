家庭共同成長系統｜模組設計規格
版本：v0.3 教育母架構同步（2026-10-08）
用途：供產品設計直接修改；修改後可作為下一次系統升級依據。

標記規則：
【已決策】＝目前已確認方向
【MVP】＝目前測試版應納入
【後續】＝保留但不要求目前完成
【待決策】＝尚未定案，請直接修改此處
【紅線】＝不可因新增功能而破壞的核心原則

==================================================
定位
==================================================
這是整個產品最重要的教育引擎之一。

目的不是告訴孩子「你完成任務了」，
而是幫孩子建立：
「我剛才做的行動 → 代表我正在學會某種能力」。

==================================================
核心格式
==================================================
我做了什麼
→ 我學會什麼
→ 這代表什麼能力／價值
→ 它如何幫助自己或別人。

例：
整理書包
→「自己的事情，我可以自己準備。」
→ 🌱 獨立自主。

生氣後冷靜
→「我可以很生氣，但我可以選擇怎麼做。」
→ 😊 情緒管理。

幫弟弟
→「看到別人需要幫忙，我可以伸出手。」
→ ❤️ 善良／同理。

完成四週儲蓄
→「願意等待，可以幫助我完成更大的目標。」
→ 🐷 延遲滿足。

==================================================
觸發規則
==================================================
1. 第一次完成
   明確教學。

2. 成長時刻
   例如以前要提醒，現在自己記得。

3. 特殊事件
   冒險、挑戰、品格事件、情緒事件、家庭事件。

4. 一般重複任務
   原則上不重複跳相同教育頁。

==================================================
畫面
==================================================
標題：「我學會了！」
主圖示／插圖
一句核心學習句
成長標籤
語音播放
主要按鈕：「知道了！」

完成任務時順序：
完成 → 我學會了 → 獎勵動畫。
不是先給獎勵再教育。

==================================================
大孩子自我反思
==================================================
偶爾改成：
「你覺得今天學到了什麼？」

圖示選項：
🌱 自己完成
💪 沒放棄
❤️ 幫助別人
😊 認識自己的感覺
🐷 願意等待／規劃

讓教育從「大人告訴我」逐漸變成「我自己能辨認」。

==================================================
資料欄位
==================================================
learning_event_id
source_event_id
child_id
trigger_type
action_text
learning_sentence
abilities（六大能力 ID 陣列，可多項）
subskills（後續可選）
autonomy（自主程度，可空）
growthOutcome（自信／自我效能等成長結果，可空）
value_tag
shown_at
child_response（可選）
added_to_passport

【紅線】
- 不要每做一次刷牙都教訓一次。
- 文案短、具體，不說教。
- 不使用「你真乖」。
- 不把教育頁變成考試。

【待決策】
- 是否讓孩子錄語音說「我學到什麼」：目前不要。
- 是否保留孩子自選答案：先讓孩子建立習慣為優先，學會了也是慢慢累積過後孩子才會知道原來做這件事背後的意義是甚麼。


【2026-10-08 教育母架構同步・已定案】
能力映射按教育功能：生活任務→自主＋選擇；情緒事件→情緒＋選擇；被看見→品格＋關係；財商決策→資源＋選擇。
不以選對為目標，不以懲罰作承擔結果；重要節點保留先學習再遊戲回饋。旧自由文字 skill 保留供歷史閱讀，不再充當母架構。
