家庭共同成長系統｜情緒教育模組｜最新確認規格 v2.5
基準日期：2026-10-08
此文件為原有 06 規格的「最新確認版本」；舊版原文另存於「原始TXT備份」。
標記：【已確認】用戶已確定；【待決策】仍不得自行實作為正式定案。

一、教育核心【已確認】
所有情緒都可以存在，但行為可以選擇。情緒紀錄不屬任務、無星星、不懲罰、可提前結束。

二、四畫面與分流【已確認】
01 😊 我的感覺：九情緒（開心、平靜、難過、生氣、害怕、緊張、累、興奮、不知道）及強度1/2/3同一畫面；圖示、文字、數字輔助。
02 💬 我想表達：原因先大類再原地展開具體選項，可跨類最多兩個；同頁選大人、靜默、小白熊傾訴方式。
03 💛 我需要：整合需要與照顧方法，六情緒各七項，單輪最多兩項，各別提示及「我試過了」。
04 🌱 我的發現：好多了、好一點、還是一樣、更強烈；後兩項可由孩子自選再試、休息或找大人，最多額外兩輪；重要覺察才強化「我學會了」，否則中性結語。
短流程：開心、平靜、興奮 → 略過「我需要」及調節回看；簡短結語。
完整流程：難過、生氣、害怕、緊張、累、不知道。

三、傾訴權限【已確認】
我想跟大人說：家長可直接回應。
我不想跟大人說：家長可查看但僅靜默陪伴，不能傳一般回覆；安全事件例外須另訂具體通報權限。
我想跟小白熊說：家長從固定句庫選句，孩子看到透明來源「由家人選擇」標示；同張回應卡在情緒紀錄及世界信箱雙入口，不複製記錄。
不得將「我想有人陪」等需要解讀為同意家長回覆；流程不等待家長。

四、原因正式句庫【已確認】
共九情緒×四大類、111具體原因。大類原地展開，最多兩原因、可跨類。共通入口「其他事情」「我不知道原因」「我不想說原因」，不得強迫文字。

【開心】
家人：和家人一起做喜歡的事／家人陪我玩／有人注意到我的努力
朋友：跟朋友玩得開心／認識新朋友／朋友幫助了我
我自己：我完成一件事／我學會新東西／我勇敢嘗試了
喜歡的事：玩了喜歡的遊戲／收到喜歡的東西／發生期待的好事

【平靜】
周圍環境：待在舒服的地方／周圍很安靜／這裡讓我覺得安全
休息時間：我休息了一下／做了輕鬆的事／睡得很舒服
有人陪伴：有人安靜地陪我／有人理解我的感受／跟喜歡的人在一起
我的狀態：事情暫時告一段落／今天沒有特別的事／剛剛慢慢平靜下來

【難過】
朋友：朋友沒有找我玩／跟朋友吵架／朋友說了讓我難過的話／我沒有一起參加活動
家人：跟家人有爭執／家人沒有聽懂我的意思／我想念家人
我自己：努力了但沒成功／我做錯一件事／結果跟我期待的不一樣
失去與想念：喜歡的東西不見了／跟喜歡的人分開／我很想念某個人

【生氣】
跟別人相處：有人拿我的東西／有人一直打擾我／跟別人吵架／有人說了讓我不舒服的話
公平與約定：我覺得不公平／有人沒有遵守約定／我沒有機會表達想法
家人與要求：家人不讓我做想做的事／我覺得被誤會／有人一直催我
做事情：一直做不好／計畫突然改變／事情沒有照我想的進行

【害怕】
環境與聲音：周圍很黑／聽到嚇人的聲音／待在不熟悉的地方
人與互動：有人讓我害怕／有人大聲對我說話／有人做了讓我不舒服的事
身體與安全：我擔心受傷／有人傷害或威脅我／我擔心別人受傷
不確定的事：不知道接下來會怎樣／要面對沒做過的事／想到可能發生的壞事

【緊張】
表現與挑戰：要上台表演／要參加比賽／擔心自己做不好
學校與學習：要考試／作業還沒完成／有人要檢查我的成果
人際互動：要認識新朋友／要說出自己的想法／擔心別人怎麼看我
新事物與時間：要去陌生地方／不知道該先做什麼／快來不及了

【累】
睡眠：昨天沒睡好／今天太早起床／現在很想睡覺
身體活動：今天活動很多／走了很多路／身體不舒服
學習與任務：學習太久／做了好多事情／一直沒有休息
心裡的事情：一直想很多事／跟別人相處後很累／今天發生太多事

【興奮】
期待活動：快要出去玩／有期待很久的活動／要參加特別的事情
人與相聚：快見到喜歡的人／朋友要來找我／要跟家人一起玩
挑戰與成果：快輪到我上場／完成期待的挑戰／發現有趣的新東西
喜歡的事：快收到喜歡的東西／要玩喜歡的遊戲／有讓我期待的驚喜

【不知道】
身體感覺：肚子緊緊的／心跳快快的／想哭但不知道為什麼／身體沒有力氣
今天的事情：好多事情一起發生／跟別人相處後怪怪的／事情突然改變
心裡的感覺：一直想到某件事／有點怪怪的卻說不清楚／同時有好幾種感覺
沒有明確原因：突然有這種感覺／現在想不到原因／真的不知道

五、「我需要」正式 42 選項與提示【已確認】
每輪最多兩項；每項個別記錄是否實際嘗試；選擇≠嘗試≠獲得滿足；可以「先這樣就好」退出。「我還不知道」不強迫嘗試。

【難過】
1. 我想抱抱 → 可以抱抱喜歡的玩偶，或找願意抱抱你的人。
2. 我想有人聽我說 → 想說的時候，可以找信任的人慢慢說。
3. 我想安靜一下 → 可以到安全、舒服的地方安靜一下。
4. 我想哭一下 → 想哭就哭一下，不用急著讓自己不難過。
5. 我想畫下來 → 可以把心裡的感覺畫出來，怎麼畫都可以。
6. 我想聽音樂 → 可以聽喜歡的音樂，看看自己有什麼感覺。
7. 我還不知道 → 還不知道需要什麼也沒關係，可以慢慢來。

【生氣】
1. 我想冷靜一下 → 可以先到安全的地方，安靜休息一下。
2. 我想有人聽我說 → 準備好時，可以找信任的人聽你說。
3. 我想被公平對待 → 可以先想想，哪件事讓你覺得不公平。
4. 我想把事情說清楚 → 準備好了，可以試著說：「我覺得……因為……」
5. 我想動一動 → 可以走走或伸展身體，用安全的方法活動。
6. 我想喝點水 → 可以先喝點水，讓自己休息一下。
7. 我還不知道 → 不知道也沒關係，可以先給自己一點時間。

【害怕】
1. 我想有人陪我 → 可以找讓你安心、能幫助你的大人陪你。
2. 我想確認自己安全 → 如果現在不安全，請先找能保護你的人幫忙。
3. 我想抱抱 → 可以抱抱玩偶，或找你信任的人抱抱。
4. 我想去亮一點的地方 → 如果周圍安全，可以到亮一點的地方。
5. 我想知道接下來會怎樣 → 可以問信任的大人，接下來會發生什麼。
6. 我想慢慢呼吸 → 如果現在安全，可以試著慢慢呼吸。
7. 我還不知道 → 不知道需要什麼也沒關係。需要保護時可以找大人。

【緊張】
1. 我想慢慢準備 → 可以把要做的事分成幾個小步驟。
2. 我想有人鼓勵我 → 可以找信任的人，請他陪你或鼓勵你。
3. 我想知道下一步 → 可以先問清楚，接下來要做什麼。
4. 我想先練習 → 可以先練習一次，不需要馬上做得很好。
5. 我想慢慢呼吸 → 可以試著慢慢呼吸，看看有沒有幫助。
6. 我想喝點水 → 可以先喝點水，休息一下。
7. 我還不知道 → 還不知道也沒關係，可以先慢慢想。

【累】
1. 我想休息一下 → 可以坐下或躺一下，讓身體休息。
2. 我想安靜一下 → 可以到比較安靜的地方，減少吵雜的聲音。
3. 我想喝水或吃點東西 → 可以喝水；如果餓了，可以吃點適合的食物。
4. 我想少做一點 → 可以找信任的大人，商量哪些事能晚點做。
5. 我想做輕鬆的事 → 可以選一件不太費力、自己喜歡的事。
6. 我想早點睡 → 可以告訴照顧你的人，今天想早點休息。
7. 我還不知道 → 可以先休息一下，慢慢留意身體的感覺。

【不知道】
1. 我想有人陪我想想 → 可以找信任的人，陪你慢慢想。
2. 我想抱抱 → 可以抱抱玩偶，或找願意抱抱你的人。
3. 我想安靜一下 → 不用現在找到答案，可以先安靜休息。
4. 我想看看身體的感覺 → 可以留意心跳、肚子、呼吸和身體的感覺。
5. 我想畫下來 → 可以用顏色或圖畫，畫出現在的感覺。
6. 我想慢慢說說看 → 可以先說幾個字，不必一次說清楚。
7. 我還不知道 → 現在還不知道也沒關係，可以先這樣就好。

六、昨天補記【已確認】
只補前一天；只填情緒、強度、最多兩原因。純歷史紀錄：家長可看，不能發一般回覆，不提供小白熊。
孩子可更正昨天補記的情緒、強度、原因；保存修改時間，不可更改事件日期。事件發生日與建立時間分別記錄。

七、資料保存與刪除【已確認】
完整原始情緒明細只保留30天；到期先生成符合隱私要求的趨勢再刪除原明細。
月度趨勢保留12個月，到期清除；不可在摘要中保存可重建個別事件的原因、原句或回覆。
孩子刪除30天內一般情緒紀錄需提出申請由家長確認；家長暫不同意，可從日常畫面隱藏並再次申請。隱藏不是刪除，家長原本查看權限不因此取消，亦不得延長30天期限。
【最新已確認】家長核准刪除：事件完全排除成長趨勢。已生成的相關摘要必須重算，無法安全重算就移除；清除相關回覆、小白熊雙入口與引用。

八、安全與隱私邊界【已確認原則；具體技術未定】
遇到「有人傷害或威脅我」或立即危險訊號，提供現實可信任成人／必要緊急協助，不得等情緒流程完成。
危險可能來自照顧者：不得一律將敏感求助或刪除申請內容自動傳給所有家長。
安全提示不代表已成功通知、通報、救援或保存證據；自動通報與安全資料獨立治理尚未獲授權。

九、尚待決策【請勿視為已確認】
安全警示觸發、通知誰、特殊權限及安全案件保存刪除政策；家長PIN操作細節；跨午夜補填更正；「我還不知道」選項互斥實作；趨勢低資料量處理及呈現；非敏感里程碑長期保存；備份清理期限；孩子隱藏紀錄恢復入口。
