家庭共同成長系統｜模組設計規格
版本：v0.3 教育母架構同步（2026-10-08）
用途：供產品設計直接修改；修改後可作為下一次系統升級依據。

標記規則：
【已決策】＝目前已確認方向
【MVP】＝目前測試版應納入
【後續】＝保留但不要求目前完成
【待決策】＝尚未定案，請直接修改此處
【紅線】＝不可因新增功能而破壞的核心原則

==================================================
MVP 要驗證的四件事
==================================================
1. 孩子會不會自己想打開？
2. 任務機制能不能推動真實生活行為？
3.「我學會了」能不能讓孩子理解行動背後的學習？
4. 家長能不能用每天約 3 分鐘維持？

Prototype v0.2 開發方向
==================================================
三個孩子獨立資料
哥哥：跆拳道
妹妹：街舞
弟弟：滑步車

三個孩子的年級：
哥哥：國小四年級
妹妹：國小三年級
弟弟：大班

每日任務上限對應：哥哥、妹妹最多 7 個；弟弟 3–5 個。

測試方式：
孩子與家長共用同一台平板，家長用 PIN 進入。

孩子端：
今天／成長／累積／獎勵／世界。

家長端：
今日總覽
待確認
任務管理
新增任務
記錄成長。

重要流程更新：
完成現實任務
→「我學會了」（重要節點）
→ 星星／成長值動畫
→ 返回。

版本升級工作方式
==================================================
1. 使用者修改本規格包。
2. 把修改後的 TXT／ZIP 交回。
3. 先做「規格差異整理」：
   新增／修改／刪除／待決策。
4. 確認後再修改系統。
5. GitHub main 作為可執行測試版來源。
6. GitHub Pages 保持同一測試網址。
